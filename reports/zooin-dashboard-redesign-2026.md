# zooin 대시보드 디자인 리뉴얼

## 목표

기존 대시보드의 과도한 색상, 이모지, 반복 카드 구조를 정리하고 리포트를 빠르게 탐색하는 업무 아카이브로 재설계했다.

## 변경 사항

- 편집실·아카이브를 모티프로 한 미니멀 비주얼 시스템 적용
- 모바일과 데스크톱에 대응하는 반응형 레이아웃 구축
- 최신 리포트 강조 영역과 스캔하기 쉬운 목록 구조 도입
- 제목·요약·태그 통합 검색 추가
- 컬렉션별 필터와 실시간 건수 표시 개선
- AI 문의 모달의 시각 디자인 및 접근성 개선
- 한국어 본문·제목·코드용 서체 체계 재정비
- 화면에 노출되던 텔레그램 호출을 서버 API 경유 방식으로 변경
- 페이지 제목과 설명 메타데이터 정비

## 검증

- Next.js 프로덕션 빌드 통과
- Chromium 데스크톱 1440px 화면 검수
- Chromium 모바일 390px 화면 검수
- 검색, 카테고리 필터, 리포트 이동 경로 확인

## 디자인 원칙

강한 포인트 컬러는 코랄 한 가지로 제한하고, 아이보리 종이 질감과 딥그린 텍스트를 사용했다. 정보 밀도가 높은 아카이브 특성을 고려해 장식보다 타이포그래피, 구분선, 여백으로 계층을 만들었다.
