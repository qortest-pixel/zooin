# zooin 가시성 및 전체 화면 통일 수정

## 수정 배경

1차 리뉴얼은 분위기와 정보 구조는 개선됐지만 데스크톱에서 본문 크기와 대비가 낮았고, 상세 보고서 및 하위 대시보드가 기존 디자인을 유지해 화면 간 일관성이 부족했다.

## 적용 범위

- 메인 리포트 대시보드
- 리포트 상세 화면
- 작업 현황
- 자동화 현황
- 프로젝트 현황
- 모바일 공통 내비게이션

## 핵심 개선

- 목록 제목을 22px, 요약을 13px 이상으로 확대
- 설명 텍스트의 명도 대비 강화
- 상세 보고서 본문을 데스크톱 17px, 모바일 16px로 조정
- 상세 본문 제목, 표, 인용문, 코드, 목록 스타일 통일
- 모든 화면에 공통 헤더와 내비게이션 적용
- 보라색 그라데이션과 이모지 중심의 기존 하위 화면 제거
- 상태 표현을 동일한 배지·진행선 체계로 통일
- 프로젝트 화면을 반응형 2열 카드 구조로 재편

## 검증

Chromium 기준 메인, 상세 보고서, 작업, 자동화, 프로젝트 화면을 각각 데스크톱 1440px 및 모바일 390px에서 확인했다. 수정 파일 ESLint와 Next.js 프로덕션 빌드가 모두 통과했다.
